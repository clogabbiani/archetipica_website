# Sito Web Archetipica - Lucrezia

## 📋 Panoramica

Questo è un sito web elegante e spirituale per Archetipica (Lucrezia), operatrice olistica specializzata in registri akashici, tarocchi, reiki, meditazioni e subliminali personalizzati.

## 🎨 Caratteristiche del Design

- **Palette Colori**: Bordeaux, oro, rosa e bianco/crema
- **Tipografia**: 
  - Cormorant Garamond (serif) per i titoli
  - Montserrat (sans-serif) per il testo
- **Stile**: Elegante, poetico, mistico e professionale
- **Responsive**: Completamente ottimizzato per mobile, tablet e desktop

## 📁 File Inclusi

1. **index.html** - Pagina principale con tutte le sezioni
2. **style.css** - Foglio di stile completo
3. **script.js** - Funzionalità JavaScript interattive
4. **logo.png** - Logo Archetipica
5. **img1.jpeg, img2.jpeg, img3.jpeg** - Foto di Lucrezia

## 🔧 Come Usare

### Opzione 1: Apertura Locale
1. Scarica tutti i file nella stessa cartella
2. Apri `index.html` con un browser web moderno (Chrome, Firefox, Safari, Edge)

### Opzione 2: Hosting Online
Per pubblicare il sito online, puoi usare servizi gratuiti come:

**Netlify (Consigliato - Gratuito)**
1. Vai su [netlify.com](https://www.netlify.com)
2. Crea un account gratuito
3. Trascina la cartella con tutti i file sul loro sito
4. Il tuo sito sarà online in pochi secondi!

**GitHub Pages (Gratuito)**
1. Crea un account su [github.com](https://github.com)
2. Crea un nuovo repository
3. Carica tutti i file
4. Nelle impostazioni, abilita GitHub Pages
5. Il tuo sito sarà disponibile su username.github.io/nome-repository

**Vercel (Gratuito)**
1. Vai su [vercel.com](https://vercel.com)
2. Connetti il tuo account GitHub
3. Importa il repository
4. Il deploy è automatico!

## 🎨 Personalizzazioni Future

### Cambiare i Colori
Modifica le variabili CSS in `style.css` (righe 14-20):
```css
--burgundy-dark: #5a2d2d;
--burgundy: #6d3838;
--gold: #c4a55a;
--rose: #e8c5c5;
```

### Aggiungere Nuove Sezioni
Copia il pattern HTML di una sezione esistente e modifica il contenuto.

### Modificare le Foto
Sostituisci i file img1.jpeg, img2.jpeg, img3.jpeg mantenendo gli stessi nomi.

### Aggiungere Più Testimonianze
In `index.html`, duplica il blocco `.testimonial-card` e modifica il contenuto.
